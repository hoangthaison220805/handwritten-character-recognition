# Handwritten Character Recognition

Handwritten character recognition system based on ResNet architecture.

## Features
- Recognition of 62 classes (0-9, A-Z, a-z)
- EMNIST ByClass dataset
- OpenCV character segmentation
- Tkinter GUI
- Confidence score visualization

## Technologies
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Pandas
